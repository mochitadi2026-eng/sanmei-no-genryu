# 第5話｜十大主星は、どこから来たのか

貫索星、石門星、鳳閣星、調舒星。

算命学のキャラクターを考えていると、十種類の星にはそれぞれ別々の個性があるように見える。では、その十という数や名前は、最初からあったのだろうか。

前回は、唐代の韓愈が李虚中の出生年月日と干支を用いた術を記録していたことを確認した。ここから先は、人が生まれた日の「干」を中心に、他の干との関係を読む仕組みに目を向けたい。

## 自分を基準にして、関係を読む

明代の命理書『三命通会』巻五「論古人立印食官財名義」は、甲・乙を例として、日干を基準とする考え方を説明している。[S09]

木の日干を自分とすると、水は木を生じ、木は火を生じ、金は木を剋し、木は土を剋す。そこから文献は、印・食・官・財という関係名を導いている。

たとえば、日干が甲ならば、壬・癸は自分を生む水、丙・丁は自分が生む火、庚・辛は自分を剋す金、戊・己は自分が剋す土として整理される。甲と乙の陰陽の違いも、文献中で意識されている。

『三命通会』巻六「論食神」には、甲の日干に対して丙を食神、壬を偏印とする具体例もある。[S10]

ここで注目したいのは、「十種類の星がまず存在して、人に割り当てられる」という順序ではなく、干同士の関係から呼び名が導かれていることだ。

## 現代の十大主星と比べる

現代の算命学の公開解説では、日干との五行の関係と陰陽の組み合わせにより、十大主星を求める。[S11] 甲を日干としたとき、次の対応を整理できる。[S13]

| 相手の干 | 算命学の十大主星 | 四柱推命で用いられる通変星名 |
|---|---|---|
| 甲 | 貫索星 | 比肩 |
| 乙 | 石門星 | 劫財 |
| 丙 | 鳳閣星 | 食神 |
| 丁 | 調舒星 | 傷官 |
| 戊 | 禄存星 | 偏財 |
| 己 | 司禄星 | 正財 |
| 庚 | 車騎星 | 偏官（七殺） |
| 辛 | 牽牛星 | 正官 |
| 壬 | 龍高星 | 偏印 |
| 癸 | 玉堂星 | 正印（印綬） |

この表は、現代に使われる二つの体系を甲の日干という同じ条件で照合したものだ。**対応する計算関係があること**を示すが、**どの時代に日本の星名が成立したか**を示す証拠ではない。

## 同じ規則でも、語り方は変わる

『三命通会』巻五では、印を父母の庇護、官を官職と統制、財を妻や財産など、当時の社会の関係にたとえて説明する。[S09]

現代の算命学では、同じ種類の干の関係を、守備・伝達・引力・攻撃・習得といった本能の枠組みで説明する例がある。[S11]

これらを比べると、計算の骨格と、それを人間のどんな側面として語るかは、分けて調べる必要があると分かる。

なお、宋代の命理書『五行精紀』には「並論十神」という見出しが見える。[S12] しかし、**見出しに十神とあるだけでは、現代の十の通変星と同じ一覧や意味だと確定できない**。文献の本文、用語の具体的な使い方、諸版本を照合する必要がある。

## 名前を変えた人は、誰なのか

現時点で確認できたことは、明代の文献に日干を基準に五行の関係を読む仕組みが記されていること。そして、現代日本の十大主星が、その関係に対応するかたちで運用されていることだ。

それでも、貫索星や石門星といった名称がいつ、誰によって、どの典拠をもとに採用されたのかは、今回確認した資料だけでは分からない。

次に必要なのは『原典算命学大系』など日本側の刊本を直接調べ、名称、算出方法、解釈をページ単位で比較する作業である。

歴史をたどる面白さは、似ているものを一つにまとめることではない。同じところを見つけ、そのうえで違うところを見つけることだと思う。

**原典で確認**：『三命通会』巻五・巻六の日干と五行関係についての説明。『五行精紀』の「並論十神」という見出しとその節の本文。  
**現代の解説で確認**：十大主星を日干との五行関係・陰陽から求める説明。
