# 比較研究ノート｜四柱の成立と三柱への再構成

最終調査：2026-10-30／版 v0.4.0

## 2. 一致・不一致の要点

- **唐代の墓誌**：「始生年月日所直日辰支干」（翻刻の句読点に揺れがある）。「時」の一字だけから、独立した時柱を採用したとは立証しない。
- **宋代に帰される編纂資料**：『五行精紀』巻十には、「年与月」「月与日」「日与时」の組み合わせの説明があり、年・月・日・時を使う技法は明代以前の伝世文献に見える。
- **明代の再叙述**：『三命通会』は李虚中も日干を基準に時を合わせたとする。これを唐代の墓誌に優先するかは史料批判が必要。
- **子平の位置**：『三命通会』は年本と日主を対比するが、子平術の成立年・単独創始者は研究上の議論が残る（S20、S21）。
- **現代の算命学**：年・月・日を用いる実務（S22）と、中国の四柱命理のどちらが先でどちらが後という一方向の進化史は、現在の資料からは描けない。

## 3. 結論と推論の区別

**史料事実**
1. 韓愈の墓誌は年月日を記すが時柱完成を明記しない。
2. 『五行精紀』巻十には年月日時を使う説明がある。
3. 『三命通会』巻二は四柱を明記する。
4. 現代の日本語実務資料に、出生時刻を使わない三柱命式がある。

**推論・研究仮説（未確定）**
1. 年本から日主への理論的重心の移動には複数の説明系譜が関わった可能性。
2. 日本の現代算命学が、四柱の存在を知りつつ特定の理念に基づいて時柱を採用しなかった可能性。ただし採否の歴史過程は未確認。
3. 唐代から現代へと一本線でつなぐ説明は現状の史料では不足。

## 4. 研究上の追加課題

- [ ] 韓愈の墓誌の『全唐文』本文と『昌黎先生集』など校訂本を比較して、句読点・異字・「年時」の語義を確かめる。
- [ ] 『五行精紀』巻十の「李虚中書」「金書命訣」「閻冬叟書」に対応する現存文献と書誌を追う。
- [ ] 徐大升『徐子平』の現物・影印・本文を調べ、日主・年月日時についてページを特定する（S21の抄録だけで本文内容を断定しない）。
- [ ] 董向慧2011論文と、その議論相手である劉国忠2009論文を本文で比較する。
- [ ] 『三命通会』の清代四庫全書本と明代の刊本の同段落を比較する。『四庫全書』所収の『三命通会』提要が著者帰属や後代坊刻の混入に言及することはS23で確認。ただし、個別の古刊本・影印画像は未校合。
- [ ] 高尾義政『原典算命学大系』等日本側刊本を入手し、命式の柱数、出生時刻の扱い、蔵干、人体星図を頁単位で照合する。
- [ ] 現代日本の「三柱を使う理由」の初出と採用範囲（流派差）を確かめる。
- [ ] 現代の命式の見せ方（陰占・陽占・人体星図）を中国古典のどの分類と比較可能か検討する。
