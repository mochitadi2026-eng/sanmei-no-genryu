# 十干の原点｜殷代の日付記号から漢代の万物循環、後世の自然物比喩まで

調査日：2026-10-31（JST）  
状態：**学術論文の全文と、古典の公開翻刻の該当箇所を確認。甲骨個別片の影印・番号と各原刊本は未校合。**

## 研究の要旨

**甲＝大樹、乙＝草花、丙＝太陽といった現代算命学の象意は、殷代の十干の記号自体の確定した原義ではない。** 十干の史料に確認できる層を順序立てて分ける。

1. **殷代後期**：日を数える10個の記号として甲骨文に現れ、十二支と組み合わせて六十日循環を構成する。王室の祖先や祭祀日とも関係する。文字そのものの古代の象形的原義は未確定。
2. **後代の相関的宇宙論**：甲乙＝木、丙丁＝火、戊己＝土、庚辛＝金、壬癸＝水と陰陽が結びつく。『礼記』「月令」等で季節・方向との対応を確認できるが、**甲骨にすでに五行の属性が備わっていたわけではない**。
3. **漢代の暦論**：『漢書』「律暦志上」は十干を万物の芽生え・成長・成熟・収蔵の語感に当てる。これは歴史上の**当時の解釈**であって、殷代の字形の語源を遡及的に実証するものではない。
4. **後代の命理**：『滴天髓』の現存伝世本文の「天干論」に、大木・枝葉・山岡・田園・汪洋という具体的なイメージや運用条件が出てくる。現代の典型的な十干キャラ像はこのような後世の命理象意に近いが、書物の原著と注釈の成立を分ける必要がある。

## 1. 甲骨資料の史料的意味

学術研究：
- William G. Boltz, “The Chinese Sexagenary Cycle and the Origin of the Chinese Writing System,” in *Culture and Cognition*, 2019, DOI: **10.34663/9783945561355-05**。全文公開：https://www.mprl-series.mpg.de/proceedings/11/5/index.html
- Cambridge University Press, “Evolution of the calendar in Shang China,” *The Archaeology of Measurement*, 2010, pp.195–202, DOI:10.1017/CBO9780511760822.021。抄録公開：https://www.cambridge.org/core/books/abs/archaeology-of-measurement/evolution-of-the-calendar-in-shang-china/C6465ACCE5ACC6D6EF27922B8665EAA4
- 中央研究院歴史語言研究所の商代青銅器・十干による祖先と氏族の分析：https://www1.ihp.sinica.edu.tw/en/Publications/Bulletin/67/Article/244

Boltzは、甲骨文に見える10＋12の文字は**数字・序数的な日付記号**として使用されており、後世の五行・色・十二生肖などの意味づけを殷代に投影すべきではないと論じる。六十干支の組は卜辞の日時句にも出る。同論文には丙辰で始まる卜辞の一例が掲載されている（出土片番号の原表画像は未独立確認）。
十干は王室祖先の追号・祭祀日でも使用されるが、その用途の起源や意味には諸説がある。中央研究院の論文には氏族名との関係を論じる別の仮説もあるため、「誰が何のために10を創始したか」とまで断定しない。
国立国会図書館の一般解説：https://www.ndl.go.jp/koyomi/chapter3/s1.html

## 2. 季節・五行への対応を示す古典

『礼記』「月令」は春の甲乙、夏の丙丁、中央土の戊己、秋の庚辛、冬の壬癸を対応づける。章の成立時期・現存諸版は未校合。

- 『礼記』「月令」と注疏を併記する公開本文：https://www.chineseclassic.com/content/1396
- 隋・蕭吉『五行大義』巻二「論四時休王」「論徳」など、五行・陰陽の関係を詳細に説明する公開翻刻：京都大学人文科学研究所サイト https://www.zinbun.kyoto-u.ac.jp/~takeda/kyoudou/gogyou/gogyoutaigi/gogyo_gogyo_02_g.html

区別：**十干という記号の古さ ≠ 五行と結びつけた説の同時代性**。また、『礼記』や『五行大義』に人格診断として甲＝大樹が書かれているとはいえない。

## 3. 『漢書』律暦志上の10の説明

『漢書』「律暦志上」の一連の原文は、「出甲於甲、奮軋於乙、明炳於丙、大盛於丁、豐楙於戊、理紀於己、斂更於庚、悉新於辛、懷任於壬、陳揆於癸」（抜粋の接続）。原典の翻刻：https://ctext.org/han-shu/lv-li-zhi-shang/zh
※今回この本文は検索結果で確認。URLを直接開くと403となるため、本文画像または独立した原刊本との校合は未了。別の転写は『礼記』注疏・清代『御定星暦考原』「十干」に収録：https://www.shidianguji.com/book/SK1618/chapter/1jurstq67oeuq

| 干 | 原文での表現 | 当時の説明の要旨（文字の元祖の語源ではない） |
|---|---|---|
| 甲 | 出甲 | ものが殻・覆いから現れる |
| 乙 | 奮軋 | 押し曲げられつつ伸び出る |
| 丙 | 明炳 | はっきり輝く、明瞭になる |
| 丁 | 大盛 | 十分に成長して盛んな状態 |
| 戊 | 豐楙 | 草木などが豊かに茂る |
| 己 | 理紀 | 条理や筋道が整う |
| 庚 | 斂更 | 収めて変化・更新する |
| 辛 | 悉新 | すっかり新しくなる |
| 壬 | 懷任 | 内に宿して担う |
| 癸 | 陳揆 | あらわれたものを測る・見定める |

この10の語義は**芽生え→盛り→整理・更新→内在**という宇宙論的循環の一つの解釈で、現代の「甲＝大樹」「辛＝宝石」等とは別。

## 4. 『滴天髓』「天干論」の後世の自然物比喩

確認した現存伝世本文と注釈：https://zh.wikisource.org/wiki/滴天髓 （各干の漢字と散文注を区別）。
原著・旧注・清代任鉄樵注を含む成立・帰属については未確定で、**甲木參天の短句と「甲為根幹之木」の散文説明を同じ著者・同じ時代の筆とは断定しない**。

| 干 | 後世本文の典型表現 | 現代のキャラ象意との関係 |
|---|---|---|
| 甲 | 甲木參天、甲為根幹之木 | 大樹・幹という象意が明示される |
| 乙 | 乙木雖柔、乙為枝葉之木 | 葉・草花・蔓が見える |
| 丙 | 丙火猛烈、丙為焚烈之火 | 強い火。太陽への同定はさらに別の象徴化 |
| 丁 | 丁火柔中、丁為溫煖之火 | 柔らかな熱。蝋燭という物の指定はこの句だけでは出ない |
| 戊 | 戊土固重、戊為山岡之土 | 山・大地の重さ |
| 己 | 己土卑濕、己為田園之土 | 田園・湿った土 |
| 庚 | 庚金帶煞、剛強為最 | 強い金。刀剣は後世の例示的イメージ |
| 辛 | 辛金軟弱、非珠玉之謂 | **注釈に「珠玉のことではない」とある**。辛＝宝石を唯一の古典原義にしない |
| 壬 | 壬水汪洋。注には百川・雨露ともある | 広い水のイメージ。海のみに限定しない |
| 癸 | 癸水至弱、上達天津 | 柔微な水。「雨粒」を殷代からの原義にしない |

重要な違い：
- 『漢書』の甲・乙・庚・辛は、**季節の変化を説明する同音・語感上の解釈**。
- 『滴天髓』の甲・乙・庚・辛は、**五行の性質を命理の運用条件と結びつけた後世の象徴**。
- 現代算命学の大樹・草花・太陽・灯火・山・田園・刀剣・宝石・海・雨は**教えやすい表現**だが、古典の同一の一文から生まれた10種の固定名ではない。

## 5. 説文解字からの遡及には注意

許慎『説文解字』（後漢）に十干の文字形や語義に関する説明があっても、殷代の甲骨文字でその形がその意味で使われていたことの直接証拠にはならない。既存S04の規則を踏襲。『説文』・『漢書』・近世命理書の文字説を**古文字学で確定した甲骨字形の原義**として再掲しない。

## 6. 十干から十大主星への接続

- 単一の日干の五行・陰陽だけでは、十種の十大主星すべてが決まるわけではない。
- 十干**同士の二項関係**（日干と相手の干）を、相生・相剋・同類の五関係、同陰陽／異陰陽に分類することで、5×2＝10の十神構造に対応する。
- 古代の甲骨時代にこの人格判定や十大主星の10名称が存在した証拠はない。
- 診断実装では `stem_id`、`stem_element`、`stem_yinyang`、`classical_seasonal_gloss`、`late_nature_metaphor`、`modern_character_symbol` の6層を分離するのが妥当。

### 主要な今後の検証
1. 異なる甲骨の実物画像・『甲骨文合集』番号と十干の使用法を調べる。
2. 『漢書』「律暦志上」原刊本の同字（楙／茂、斂更／改更等）を刊本ごとに比較する。
3. 『滴天髓』の短句と注釈の成立年・筆者・初出を諸版本で特定する。
4. 甲大樹／乙草花／丙太陽／丁灯火／辛宝石という現代の10種比喩の**日本の初出**を実刊本・講義資料で追う。

**暫定結論**：日付を数える十記号が、後代に陰陽五行・季節循環の意味を負い、さらに後世の命理で具体的な自然物の象意を担った。古典の「そう書かれた時期」と、その意味が本当に生まれた時期は分けて扱う。
