# 日本算命学成立史｜一次資料調査の優先順位

更新：2026-10-30
状態：**1974年『星占い中国算命術』の実物写真124〜125頁と210〜211頁を確認。その他の頁・1974年『改姓改名術』・1980年刊の本文は未読。**

## 優先順位の決め方

1. まず「いつ、誰が、何を公表したか」が検証できる**同時代の出版物**を最優先する。
2. 古い資料を優先するが、内容を確認できない書誌情報を本文既読の証拠にしない。
3. 星の名称・三柱・時刻不使用などの成立は、**それが明記された当時のページ**を発見してから判定する。
4. 伝承は「著作にそう書かれたか」と「史実として裏付けられたか」を別々に調べる。
5. 公開書誌 → 公開目次 → 限定公開本文の合法的な閲覧・複写 → 刊本比較の順で進める。

## 2026-10-30の公開本文探索について

1974年『星占い中国算命術』の序文・目次・算出方法の公開原文は確認できなかった。ジャパンサーチではデジタルコンテンツなし（S39）。1980年の第1・2巻はNDLの書誌で遠隔複写「可」であり、複写箇所の特定後に合法的な部分複写を申し込める可能性がある（S25・S26・S40）。詳細は [1974年刊の本文アクセス調査](1974-text-access-investigation.md)。

## 新たに確認した書誌事実

### 1974年刊の2冊が1980年の全集より古い

[S31]と[S32]は国立国会図書館が所蔵し、各々1974年の刊行とする。

- 1974年の本は、**高尾義政による公刊活動が1980年より前に存在した**という確かな手掛かりである。
- ただし、この2冊が本人の**最初の出版物**と確定したわけではない。
- タイトルの「中国算命術」を、現代の算命学理論・命式と同義とはまだ認定しない。
- 当事者である高尾学館の出版物案内は、『ツキを変える 改姓改名術』を1974年8月5日、『星占い 中国算命術』を1974年9月16日と記載する [S33]。月日は学校側の記載であり、NDL書誌で独立検証できたのは1974年まで。

### 本文への到達方法

- 『原典算命学大系』第1巻について、NDLは「国立国会図書館内限定公開」「図書館・個人送信対象外」と明記する [S25]。ネットで本文が自由に読めると案内しない。
- NDLの遠隔複写は、資料と該当節・ページを指定した場合に、来館せず有料で取り寄せられる仕組みがある [S34]。適用可否・範囲・料金は資料と受取方式で異なるため、**実際に申込みが通ったとは扱わない**。
- 東京都立中央図書館は第1・2巻の紙の所蔵がNDL検索に反映されている [S35]。利用条件は館の最新情報を確認する。
- 高尾学館は2025年に再販売を案内し、現在の公式出版ページに復刻版全11巻を掲示している [S33]。**2025年以降の復刻版と1980年の原本の本文が同じかは未検証**。
- 高尾学館は東京校での閲覧も案内しているが、現地の具体的な利用可否は未確認 [S33]。
