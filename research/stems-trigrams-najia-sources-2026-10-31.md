# 十干と八卦はどこで接続したか｜納甲・八卦五行・易伝を分ける

調査：2026-10-31（JST）  
判定：**『京氏易伝』巻下の公開伝世本文に十干の八卦配当がある。『説卦伝』の八卦の象、『周易正義』の八卦五行、清代の批判は別層。京房本人の前漢原本は未校合。**

## 1. 結論

十干と八卦は**歴史的に結びつけられた**。文献上の明確な接点は、八卦に十干を配する「納甲」であり、**乾・坤に2干ずつ、残り6卦に各1干**配当する。

ただし、以下を同じ史実として扱わない。
- 殷代の十干：甲骨・干支日付、祖先祭祀の番号的な用途。
- 『周易』の八卦：陰陽の三画から構成され、天・地・雷・風・水・火・山・沢に対応。
- 十干の五行配当：甲乙木、丙丁火、戊己土、庚辛金、壬癸水。
- 八卦の五行配当：乾兌金、震巽木、坎水、離火、坤艮土。
- 納甲：乾甲壬、坤乙癸、震庚、巽辛、坎戊、離己、艮丙、兌丁。

「納甲が存在する」ことは、「八卦が十干から生まれた」「現代日本算命学の命式へ納甲をそのまま掛けてよい」の証拠ではない。

## 2. 『周易』の構造と八卦

### 『繫辭傳』上

「易有太極，是生兩儀，兩儀生四象，四象生八卦」。
- 公開本文：https://ctext.org/text.pl?if=gb&node=46934&show=parallel
- 典拠：後代の『周易』「繫辭」本文。太極→両儀→四象→八卦は象徴的構造であり、八卦が歴史上この手順で発明されたという同時代記録ではない。

### 『說卦傳』

「乾，健也。坤，順也。震，動也。巽，入也。坎，陷也。離，麗也。艮，止也。兌，說也」。
自然象は乾天・坤地・震雷・巽風・坎水・離火・艮山・兌沢。
- 原文：https://www.chinese-classics.org/read/confucius/yi-jing/appendix/shuo-gua
- 本文の成立に年代幅がある。具体的な創作年と初出は原典の本文だけでは確定しない。

## 3. 『京氏易傳』巻下：納甲の直接の記載

**刊本の層**：
- 『京氏易傳』は前漢の京房（前77–前37）に帰されるが、今回確認したのは伝世の四庫本／四部叢刊本の**公開文字翻刻**で、前漢当時の本人の原物を読んだわけではない。
- 四庫本：https://zh.wikisource.org/zh-hant/京氏易傳_(四庫全書本)/卷下
- 四部叢刊本（上海涵芬楼が明天一閣刊本を影刊した系統の公開翻刻）：https://zh.wikisource.org/zh-hant/京氏易傳_(四部叢刊本)/卷下

短い原文抜粋：「震巽之象配庚辛」「坎離之象配戊己」「艮兌之象配丙丁」。乾坤には甲乙壬癸を配すとの記述があり、本文注が甲壬を乾、乙癸を坤に分ける。

| 八卦 | 納甲で受ける十干 | 伝世本文の対照 |
|---|---|---|
| ☰ 乾 | 甲・壬 | 「乾坤之象，益之以甲乙壬癸」＋注 |
| ☷ 坤 | 乙・癸 | 同上 |
| ☳ 震 | 庚 | 「震巽之象配庚辛」 |
| ☴ 巽 | 辛 | 同上 |
| ☵ 坎 | 戊 | 「坎離之象配戊己」 |
| ☲ 離 | 己 | 同上 |
| ☶ 艮 | 丙 | 「艮兌之象配丙丁」 |
| ☱ 兌 | 丁 | 同上 |

上記は**十干を八卦に配する一つの規則**。日干から人格の10分類を作る十大主星の計算とは別の手続きである。『京氏易傳』にはほかに六十四卦・六爻・十二支・節気と結びつける術があるため、納甲を十干と八卦の名称対応だけに限定しない。

## 4. 八卦の五行 ≠ 納甲された干の五行

唐・孔穎達『周易正義』「繫辭上卷七之十一」の**疏（解説）**には、「震木、離火、兌金、坎水、巽同震木、乾同兌金、坤・艮之土」とある。
- https://zh.wikisource.org/wiki/周易正義/07.11

| 八卦 | 八卦五行（唐疏） | 納甲の干 | 納甲干の五行 |
|---|---|---|---|
| 乾 | 金 | 甲・壬 | 木・水 |
| 坤 | 土 | 乙・癸 | 木・水 |
| 震 | 木 | 庚 | 金 |
| 巽 | 木 | 辛 | 金 |
| 坎 | 水 | 戊 | 土 |
| 離 | 火 | 己 | 土 |
| 艮 | 土 | 丙 | 火 |
| 兌 | 金 | 丁 | 火 |

**重要**：乾＝金であり、乾が「甲＝木・壬＝水」を納めることは矛盾しているように見えるが、**八卦の属性**と**別の手続きで組み込まれた干**の意味が違うのである。乾を甲に置換した結果「乾の属性が木に変わる」とは説明しない。

清の黄宗羲『易學象數論』「納甲一」も、まさに八卦五行と納甲の不一致を挙げて納甲の整合性を批判している。したがって、近世の古典内部にも異論があり、占術上の全方法に共通する単一の五行対応があったわけではない。
- https://zh.wikisource.org/zh-hant/易學象數論/納甲一

## 5. 月の満ち欠けとの結合：『周易參同契』系本文

現存『周易參同契』系と朱熹『周易參同契考異』の伝世本文は、
- 月3日頃：震・庚（生明）
- 8日頃：兌・丁（上弦）
- 15日頃：乾・甲（望）
- 16日頃：巽・辛（欠け始め）
- 23日頃：艮・丙（下弦）
- 30日頃：坤・乙（晦）

と配する。例：「三日出為爽，震受庚西方」「八日兌受丁」「十五乾體就」。これは**月相と八卦・十干を象徴的に結ぶ例**であり、占断の正確さや暦の実測精度の実証ではない。
- https://zh.wikisource.org/zh/周易參同契考異
- https://ctext.org/wiki.pl?chapter=6658656&if=gb

成立について『參同契』を単純に後漢の魏伯陽の完全な本人原文とみなせない。現在の『考異』本文は宋の朱熹の註釈や後世の編纂を含む。

## 7. 算命学との接続の限界

- 十干：陰陽＋五行のそれぞれの属性。
- 十大主星：日干と相手干の**二項関係**を5関係×2陰陽で10種類に分類。
- 八卦：陰陽3線から8種類の象を作る。
- 納甲：八卦に十干を配する**別の操作**。
- 十二大従星：日干と支を十二長生・十二運により比較する現行日本の仕組み。

**算命学の命式計算に八卦の納甲を採用する必要があるという証拠は見つかっていない**。今日調査したのは、共通する古典的な思想・記号体系の歴史的な接点であって、「すべての算命学が易を直接の計算母体にしている」という証明ではない。

### 次の史料タスク
1. 『京氏易傳』四庫本／四部叢刊本の納甲本文、注釈、字体・省略の差を原刊影印・版本で校合。
2. 『參同契』の成立と註釈層を分け、初期の納甲・月相配当がどこまで確定していたかを調べる。
3. 十干・十二支・八卦を同じ六爻に置く後世の納甲筮法について、文献年代・構造・命理との違いを追う。
4. 黄宗羲の五行不一致の批判と、後世擁護論を文脈ごとに対照し、歴史上の複数の立場を明示する。
5. 現代日本の算命学の著書が納甲・八卦を計算に採用していたかは、実物の該当章で別途確認。

**結論**：つながりは実在する（納甲）。しかし、歴史的系譜・五行属性・計算上の入力・実占上の意味を混同しない。
