# 日本側成立史｜書籍以外の公開史料から確認できたこと

調査日：2026-10-30
対象：東京高裁の公式判決、朱学院の公式沿革、明学院の系譜年表、高尾義政の講義録音に関する公開案内。
**原本本文の確認範囲、学校側の説明、研究上の推測を混ぜない。**

## 1. 東京高裁の公式判決を確認できた（S42）

東京高裁・平成10年（行ケ）第256号、審決取消請求事件。
公式PDF：https://www.courts.go.jp/assets/hanrei/hanrei-pdf-13651.pdf

- **全3ページの裁判所公開PDFを確認**。以前の研究ノート（S37）では、非公式転記のみ・公式PDF未照合としていたため、検証状態を更新する。
- 公式PDFの**2ページ目「理由」**は、乙第19・21・22号証に基づいて、**1974（昭和49）年9月13日**、高尾義政と初代校長側の人物によって株式会社朱学院が設立されたと認定している。PDFの個人名は匿名化され「故E」「F」等の記号表記。人名の復元は別の学校側資料との照合であり、PDF本文にある実名ではない。
- 同じページに、山岡荘八『徳川家康』第11巻の**1973（昭和48）年4月20日発行・第20刷**で、算命学という語が中国伝来の占星術を指して使われている、とする裁判所の認定がある。
- **第20刷＝1973年に語が印刷された例**であって、1960年代の初版時点に同じ表現があったと証明したわけではない。
- 判決は高尾側の請求を棄却し、「算命学」の語の出所表示・混同の問題を判断した。**古代中国から現代日本への直接伝授や、特定流派の教義の真偽を立証する歴史論文ではない**。
- 裁判所が「古代中国に生じた占術ないし思想の名称」である点を当事者間に争いがないと述べていても、古代の特定の原典・時代・人物を独立した史料調査で立証したことにはならない。

既存の研究：[1974年刊と商標紛争](1974-book-pages-and-court-record.md)。

## 2. 朱学院の公式沿革（S43）

公式サイト：https://www.shugakuin.co.jp/message/

- 学校は**1974年に赤坂7丁目で設立、1975年に第1期生の授業開始**と説明。
- 朱学院の現行トップページは、**佐藤宗颯が高尾義政と1974年に共同設立、初代校長**と記す。
- 「日本初」という表現は学校側の評価。裁判所が認定したのは株式会社の設立等であり、**他の学校が以前に存在しなかったことの網羅的証明ではない**。
- 高尾学館公式沿革（S27）の「1972年に朱学院塾を設立」とは、**塾の開設・会社登記・授業開始**という異なる出来事を指しうる。この3つを混ぜず、それぞれの時代の資料を探す。

## 3. 別の後継系統の年表（S44）

明学院系の研究・授業方針：https://itft.co.jp/jugyo/

- 同系統の説明では**1979年に高尾義政が朱学院と袂を分かった**とされる。21人の特別研究生や、荘学院との関係も述べられる。
- **1986年1月の『荘学院 明堂会報』**、**1987年1月15日発行の同会報**を出典として挙げ、**1987年2月に東洋史観専門学校高尾学館が発足**したと記す。
- 一方、高尾学館公式沿革（S27）では**1986年に高尾学館を新小川町に設立**と書かれる。
- この違いは、どの組織の設立、校舎の開設、改称、引継ぎを指すかで説明できる可能性があるが、**現時点では判定不可**。『明堂会報』の原物・当該記事を確認する必要がある。
- 同ページの免状画像は当事者側が掲示したもの。資格・筆跡の真偽は当研究で独立検査していない。

## 4. 当時の高尾義政本人の講義を探す（S45）

明学院系公開ページ：https://itft.co.jp/listen/

サイトは以下の録音の**試聴サンプル／講義録音の存在**を案内する。

- 1981年4月25日「天中殺と心」（冒頭約15分）
- 1982年11月27日「運命の遺伝」（冒頭約11分）
- 1987年3月28日「運命と花の話」（冒頭約10分）
- 1987年5月9日「運命学講座1」（冒頭約6分）
- 1987年3月3日「占道と占芸」に関する授業（約3分41秒）

**今回、録音の実際の音声データは再生・文字起こししていない**。サイトの録音案内や記載の日付を確認した段階である。録音年の真偽、音声の本人性も未校合。

高尾学館の公式サイトは**宗家ビデオ講座**を有料・要予約で公開している：https://www.sanmei-gaku.com/lecture/ 。撮影日・収録内容の具体的な原本は未確認。

録音・動画は、原文が確認できれば後世の伝聞に頼らず**本人の当時の発言内容**に接近できる可能性がある。ただし当時の本人の発言と、話している内容の歴史的真実は別。

## 6. 結論の限界

**史料の記載として確認済み**：裁判所公式PDFに認定された1974年の法人設立と1973年版の語の用例。

**学校側の現在の説明**：1974年学校設立・1975年授業開始、1979年分派、1986〜1987年学校再編、講義録音の所蔵案内。

**未確認**：1974年の本の全体の算出規則、1973年の小説の初版の語、旧会報本文の実物、録音の肉声内容、呉仁和・呉達人の人物同一性、古代の直系伝授史。

歴史研究の観点からは、**文字として残った同時代に近い記録**（裁判所が引用した1973年刊、1974年の会社設立資料、1986/1987年の会報）を優先し、後世の流派の自己説明で足りない証拠を補わない。
