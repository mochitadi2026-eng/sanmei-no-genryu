第6話｜十二大従星の前に、十二の季節があった

天報星、天印星、天貴星。算命学では、人の一生を十二の姿になぞらえた星が並ぶ。

この十二の名前は、どこから来たのだろう。

前回は、十大主星を日干と他の干との関係から読み解いた。今回は、人の一生に似た十二の段階を、中国の古い命理書に探してみたい。

もともとは、星の性格一覧ではなかった

南宋の廖中に帰される『五行精紀』巻七「論五行一」には、長生・沐浴・冠帯・臨官・旺・衰・病・死・墓・絶・胎・養という、十二の段階が並んでいる。[S14]

そこでは『三命提要』という書物の説明を引きながら、万物が形を得て、育ち、盛んになり、衰え、しまわれ、次の循環へ入る過程を、人間の誕生から死後までになぞらえている。

たとえば、長生は生まれて伸びゆく段階、冠帯は衣冠を身につける段階、臨官は社会の役目につく段階、墓は成し遂げたものが蔵に納められる段階として語られる。

ここで使われているのは、現代的な心理テストのような十二種類の性格分類というより、五行の気の変化を十二段階でとらえる比喩である。

明代にも伝わる十二の循環

明代の『三命通会』巻二「論五行旺相休囚死並寄生十二宮」にも、十二宮が列挙されている。[S15]

長生 → 沐浴 → 冠帯 → 臨官 → 帝旺 → 衰 → 病 → 死 → 墓 → 絶 → 胎 → 養。

『五行精紀』の記述と比較すると、少なくとも明代より前に、十二段階を人の一生と重ねる考え方が命理文献に見えていたことが分かる。ただし、『三命提要』そのものの原本や初出年代を今回確定したわけではない。

もう一つ重要なことがある。『三命通会』では、盛んな状態だから必ず吉、衰えた状態だから必ず凶とは限らない、とも説いている。

「死」や「絶」という文字を、実際の寿命や不幸の宣告に置き換えて読むのは、この文献の説明としても単純すぎる。

現代の十二大従星に並べてみる

現代日本の算命学の解説では、十二大従星と十二運は、次のように対応づけられている。[S16]

中国命理・十二運日本の十二大従星人生の段階にたとえた読み
胎天報星生まれる前の胎
養天印星養育される時期
長生天貴星生まれ、育ち始める
沐浴天恍星沐浴、幼い段階
冠帯天南星衣冠を整え、成人する
臨官（建禄）天禄星役目につき、自立する
帝旺天将星盛んな時期
衰天堂星盛りを過ぎ、落ち着く
病天胡星勢いが弱まる
死天極星活動の終わり
墓天庫星蔵に収める
絶天馳星一つの循環が絶える

この並べ方なら、一見ばらばらに見える星が、十二の段階に対応していることが分かる。

ただし表の右端は、中国古典の比喩を現代語で短く整理したもので、古典からそのまま引いたキャラクター設定ではない。まして、天報星や天馳星という日本側の星名が『五行精紀』に出てくるわけでもない。

同じ十二でも、計算には検討すべき違いがある

現代の算命学の公開早見表では、たとえば甲の日干と亥の組み合わせは天貴星、甲と酉は天報星になる。乙の日干では、午が天貴星、申が天報星となる。[S17]

つまり、日干の陰陽や、組み合わせる地支によって段階の位置が変わる。

しかし、古典の側でも算出規則が一つだけだったわけではない。『五行精紀』巻七には、土の長生が申とされる説明と巳とされる説明を比較する箇所がある。[S14]

したがって、十二段階の名称の対応、十干と地支による算出規則、星に割り当てる点数や人生の時期の読み方は、それぞれ独立して確認すべきである。

星を生み出したのか、星に名前をつけ直したのか

今回、原典で確かめられたのは、宋代に帰される命理書に十二の盛衰の段階があり、明代の命理書にもその説明が載っていることだ。そして現代日本の算命学では、その十二段階と十二大従星が対応づけられている。

一方、天報・天印・天貴などの日本側の名称が誰によって、いつ定められたのかは、まだ分からない。現在使われている点数や初年期・中年期・晩年期という配置が、どの時代の資料で確認できるかも未調査だ。

キャラクターを作るなら、ここを区別しておきたい。

古典にあるのは、万物がめぐる十二の段階。その後の読み手たちは、その段階を使い、さまざまな意味を重ねてきた。

キャラクターは、長い解釈の歴史を伝える入口になる。しかし、かわいい姿にしたからといって、その姿が古代から存在していたことにはならない。

伝世本文で確認：『五行精紀』巻七の十二段階・土長生の異説、『三命通会』巻二の十二宮と吉凶の留保。
現代の二次資料で確認：十二大従星と十二運の対応、日干×地支の早見表。
未確認：十二段階の最初の成立時期、日本側の十二大従星の命名者・初出・点数体系の成立、原典から現代算命学への直接の伝承経路。
典拠：S14・S15・S16・S17
