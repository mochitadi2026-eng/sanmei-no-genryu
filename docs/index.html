星の名前が生まれる前、
人は何を見ていたのだろう。

生年月日から命運を読む方法が現れる前、人々は天候や季節、ひび割れや暦に何を尋ねていたのか。古典の本文と研究資料を確かめながら、ゆっくりたどっていく連載です。

現代の算命学にそのまま続く、という物語を最初から決めつけることはしません。章の順番は理解のための構成で、文献の成立順でも直系の系譜でもありません。分かっていることと、まだ分からないことを分けて書きます。
