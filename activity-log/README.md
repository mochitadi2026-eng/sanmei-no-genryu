## 続きを書く方法

1. 最終の[進行ログ](2026-10-30.md)を読み、**前回の事実・保留事項・次の作業**を確認する。
2. 進展があった日だけ、`activity-log/YYYY-MM-DD.md` を新規作成する。作業日時、確認できた証拠、失敗と修正、CIの結果、未確認の点、次にやることを残す。
3. 読者向けに `note-drafts/activity-diary-vol-XX-YYYY-MM-DD.md` を作る。専門的な作業ログをそのまま貼らず、**なぜ始めたか→実際に起きたこと→分かったこと・分からなかったこと→次回へ**の構成にする。
4. noteに投稿したら**本人が確認した記事URLと公開日**だけをこの一覧へ追記し、状態を「公開済み」に変更する。投稿前に勝手に公開済みとしない。
5. **vol.5は未作成**。実際の進捗に応じて題材を決める。テストが成功した事実と、算命学の歴史的正しさは別。

## 表現のルール

- たぢさんの一人称で、親しみがあり、ときどき「あんた」「〜わね」を使うが、口癖を詰め込みすぎない。
- AIっぽい過剰な名言・断定・過度な誇張を避ける。
- **確認した史実・文献の記載・伝承・仮説・未確認**を明確に区別する。
- 原本未読なら「読んだ」と書かない。テスト未実行なら「合格」と書かない。
- 読者にとって意味のある発見を主にして、コミットやテスト件数は必要な範囲で具体的に記す。
