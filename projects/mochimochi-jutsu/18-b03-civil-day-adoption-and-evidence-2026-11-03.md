# B03｜固定もちキャラの日界採用・出典比較・実装仕様 v1

決定日：2026-11-03（ユーザーから方針の実施指示）
状態：**もちもち占術独自の出生キャラ分類では0時民用日界を採用**。算命学の学校の公式方式であるとの認定ではない。M06命式エンジンの正式採用／本番公開とは別。

## 1. 採用した規則（独自分類／編集上の決定）

| 項目 | B03の採用方針 |
| --- | --- |
| ルールID | `mochimochi-birth-character-v1.0` |
| 用途 | もちもち占術の固定キャラ判定だけ |
| 入力 | **日本で登録された西暦（グレゴリオ暦）の出生日** |
| 1日の切り替え | **民用日の午前0時**。23時台は記録上のその日 |
| 日の干支 | 日付から60干支周期を求める。B02では実M06と73,049暦日一致・公開暦11日一致 |
| 12キャラ | 日干支の**十二支（日支）**から`BC01〜BC12`を選ぶ |
| 5属性 | 日干の**五行（木／火／土／金／水）**を選ぶ |
| 全分類数 | 12×5＝60。干支の陰陽整合性により各組み合わせが一意 |
| 別の判定 | 既存MT01〜MT12の5問の「今のもち具合」は固定キャラを変えない |
| 別の占術計算 | 年・月柱の節入り時刻、大運・年運、蔵干の決定には今回の0時規則を転用しない |
| 対応範囲 | 開発用は日本で記録された1900〜2027年の民用日（歴史的な時計制度・海外出生は本格命式と区別） |
| 公開・個人情報 | 現段階で本番公開不可。入力は保管せず、公開GitHubに実ユーザーの生年月日を載せない |

**採用の意味は「この独自キャラ設計で使う計算上の規約を固定した」ということのみ**。性格を科学的に測定したと主張しない。算命学の学校がこの独自ルールを公認したとも表示しない。

## 2. 事実・推論・編集上の採用を分ける

### 一次資料に記載された事実

1. [朱学院公式「算命学と四柱推命の違い」](https://www.shugakuin.co.jp/basics/sichuusuimei)：算命学では出生時刻が不要と説明している。**このページに、日干支の切り替えが午前0時であるという明文はない。**
2. [高尾学館「星出し」](https://www.sanmei-gaku.com/yourself/)：生年月日の入力による計算を提供している。**入力欄に時刻がないことだけでは、日界が0時であると断定できない。** 高尾学館の条件に従い、サイトの出力・画像等を無断でコピーしていない。
3. [算命学 鑑定ノート「計算の方法」](https://kanteinote.com/sanmeigaku/method/)（公開ページ更新2026-10-17）：運営者は自らの計算機で日干支を**午前0時**で切り替え、23時台を翌日に送らないと明記している。**これは計算機の公開仕様であり、朱学院・高尾学館による規則の認定ではない。**
4. [朱学院「六十干支」](https://www.shugakuin.co.jp/basics/sanmeigaku-rokujikkanshi)：日干支の60通りを示す。**12キャラ×5属性という分類は当プロジェクト独自の付加設計であり、公式に存在するタイプ名ではない。**
5. 参考比較：[E-計算！四柱推命](https://e-keisan.com/fortune/shichu-suimei.html)では日界について0時説と23時説の違いを説明しているが、**四柱推命の記述をそのまま算命学の規則として採用しない**。

### 編集上の採用判断

- もちもち占術は、動物占い・星座占いのように**生年月日だけで変わらない固定キャラを提供する独自コンテンツ**を目指す。
- 時刻不明でも毎回同じキャラを得られるルールを優先して、**日本で記録された民用日をそのまま使う午前0時日界**を採用。
- 性格や人生の出来事への「的中」の科学的根拠ではなく、暦記号を説明できる編集上の識別子として使う。
- 方式を変える場合は`rule_version`の改定と旧版との比較を行い、本人の過去に合うよう後付けで日界を動かさない。

## 3. 実装の境界

[元のB03候補関数](b03-civil-date-character-candidate-v0.1.mjs)は創作の数値モデルとして保持。

[今回採用したB03の入り口](b03-adopted-birth-character-rule-v1.mjs)は候補関数を使いつつ、
- `rule_status: adopted_original_character_convention`で**独自ルールとして採用した事実**を返す。
- `production_usable:false` / `published_character_assigned:false` / `personal_traits_inferred:false`で**本番利用や正式な個人鑑定は未審査**と明示する。
- 出生時間、性別、相談履歴、5問回答等の追加フィールドを受け取らず、意図的に日時換算しない。
- 元の`tadi-sanmei-desk`のM06は変更していない。**M06の23時台の`needs_review`は残る**。本格命式と固定キャラを同じAPIにしない。
- 12キャラの名称・見た目・60詳細分類の解説・M11画面はB04/B05以降。キャラ名を勝手に公開しない。
