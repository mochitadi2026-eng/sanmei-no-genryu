## 境界

古典の記述、現行算命学の計算方法、もちもち独自の創作を区別する。命式計算の検証が終わるまで、生年月日による結果を正しいと保証しない。自己理解の演出と心理学的な特性測定は別。画像質問は医療・心理検査ではない。

このリポジトリは公開されている。実際の相談・生年月日・回答など個人データをコミットしない。
