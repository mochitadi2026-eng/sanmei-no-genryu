## 取り扱い上の制約

1. 保存された強み・弱みは占い・算命学の説明から収集した**解釈候補**。実在人物の性格を科学的に確定するものではない。
2. 一般干支占いは生まれ年を扱う場合も多い。年支の解釈を日支の実証済み特性として転用しない。
3. **四層は固定**：五行＝餅素材、十二支＝餅種類・本体、十大主星＝メイン具材、十二大従星＝器。具体的な素材・具材・器の割当は未決定。
4. **基本60分類は日支12×日干五行5**。十干を第5層に増やさない。十二支自身の五行と日干五行は区別する。
5. 既存の十二支12画像は正式採用済み・修正不要。名前・持ち味・物語上の役割は審査待ちで、資料を登録したからといって確定にはしない。
6. 星の命式上の採用位置は未決定。キャラの既存22教育用案内役を置き換えない。
7. JSONのrecord_statusは research_candidates_unapproved。公開・鑑定の自動出力・販売への接続は別審査。

## 使用例

- sets.zodiac[0].weaknesses：子の弱点候補。
- sets.zodiac[0].behavior_summary：子の行動イメージ。
- sets.main_stars[0].instinct：貫索星の本能区分。
- sets.follower_stars[0].traditional_energy_points：占術上の象徴点数（実際の体力値ではない）。
- sets.stems[0].nature_symbol：甲の自然物の象徴。
