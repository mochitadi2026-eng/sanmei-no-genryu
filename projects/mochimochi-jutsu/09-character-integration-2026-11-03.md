## 1. 現在の決定

もちもち占術には**混同してはいけない3種類のもの**がある。

| 群 | 元の意味 | この開発での用途 | 何をしないか |
| --- | --- | --- | --- |
| 十大主星の動物10体 | 現代算命学の主星名称に対応する創作動物 | 象徴や用語を学ぶための案内役 | M08の5問結果を星の命式として扱わない |
| 十二大従星の式神12体 | 現代算命学の従星名称をもとにした創作式神 | 象徴と名称を見て楽しむ図鑑・物語 | 12という数が同じという理由で12もちタイプに1対1対応させない |
| 独自の12もちタイプ（MT01〜MT12） | M08の選択肢に基づく暫定ラベル | M09で回答の振り返り文を表示 | 古典の星名や確定した性格と呼ばない |

M06で伝統の命式計算が完全に検証・本番承認されるまでは、**生年月日をもとに自動でキャラを割り当てない**。命式が分かっても性格を実証できるということにはならない。

- [M10キャラカタログ](m10-character-catalog-v0.1.json)：MS01〜MS10（動物）、FS01〜FS12（頭巾の式神）の22件。対応星名・キャラ名・独自の小道具・代替テキストを登録。

## 3. キャラの外観はどこまで決まっているか

- 十大主星の動物：岩亀、森狐、陽猫、月兎、福狸、実り栗鼠、風虎、銀鶴、旅龍、知恵蛇。**M02の並び**に準拠。動物の画像が対応できるファイルの正確な保存場所は未確認。
- 十二大従星の式神：全員2.5〜3頭身を目安とした人間寄りのミニキャラ。頭巾、簡素な和装、持ち物を主役とする。ぽぽ＝種袋と芽、ころ＝鈴、きき＝虫めがね、きらり＝手鏡、いぶき＝わらじ、こつぶ＝そろばん、たいが＝扇、しずく＝湯のみ、ゆめ＝万華鏡、ふわり＝風鈴、くるり＝小箱、ひゅう＝風車。
- **画像の完成・透過確認・GitHubパス確認をしたわけではない**。M10カタログでは`visual.asset_path=null`と明記し、テキストと代替説明だけでも表示可能にする。
- 身体の指、手足の形、道具の見分けやすさ、透過PNGの有無は、実画像ファイルの確認が済んだ段階で初めて合格を付ける。

## 4. 表示・配慮・検証の契約

```js
import sourceM02 from './m02-core-symbols-v0.1.json' with {type:'json'};
import catalog from './m10-character-catalog-v0.1.json' with {type:'json'};
import {buildCharacterGallery} from './m10-character-gallery-v0.1.mjs';

const gallery=buildCharacterGallery({catalog,sourceM02,family:'all'});
// gallery.status === 'educational_only'
// gallery.cards.length === 22
// gallery.cards[0].name === '岩亀'
// gallery.cards[0].image === null
```

- 図鑑へアクセスするのは本人の任意の操作。回答から「あなたは岩亀」「天報星の人」などの推定をしない。
- 画像がないカードは**画像なし**で表示し、ALTを文章情報として利用。存在しないファイルパスを作らない。
- 星の原典と、現代日本における星の名称対応と、もちもち占術の創作ビジュアルを、別の意味のものとして説明する。
- 将来M11でカードやギャラリーの画面を作る場合は、スクリーンリーダー、文字サイズ、色のコントラスト、スマホ表示を確認する。
- 独自タイプが未判定でもギャラリーは表示できるが、個人への推薦カードとしては出さない。
