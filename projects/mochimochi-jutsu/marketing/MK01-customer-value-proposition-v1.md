### 企画上の一文（外向けコピーではなく内部での価値定義）

> もちもち占術は、自分の個性や歩みを見つめ直したい人に、暦の象徴と今の自分の言葉を分けて示し、人生を一つの物語として読み直すきっかけを届ける、自己理解のためのオリジナル占術。

**この一文の「読み直す」は自己省察の意味であり、実際の過去を的中させる科学的能力の主張ではない。**

### 推定インサイト（I）
「自分のことを知りたい。でも、自分を誰かに決めつけてほしいわけじゃない。自分でも気づいていなかった見方を、面白い読み物として受け取りたい。」

これは調査による本人の発言ではない。実証された心理ではなく、商品の訴求仮説。

### ウォンツ／ニーズ／JTBDの区別

- ウォンツ（I）：自分専用のもちキャラ、短い鑑定結果、過去と今をつなぐ物語。
- ニーズ（I）：自己理解、振り返り、日常で考える材料。
- JTBD（I）：自身を見直すタイミングで、今の状況とこれまでの歩みを整理するきっかけを得る。
- ベネフィット（設計）：新しい視点、読みやすさ、選択する余地、説明可能性。
- 避ける約束：科学的性格検査、過去の的中保証、未来の確定、人生の改善保証。

## 5. 無料と有料の価値の境界（D：商品仕様ではなく価値提案）

| 比較 | 無料の基本体験 | 有料候補の物語鑑定 |
| --- | --- | --- |
| 顧客が得たいこと | 今の自分を気軽に振り返る | 自分の時間軸をより深く読み直す |
| 中心の体験 | 現在の5問 → もち具合の読みやすいミニ物語 → 持ち帰る一問 | 検証済み暦の個別シグナル → 過去の候補時期・現在の回答・今後の視点をつなぐ章立ての読み物 |
| 無料でも完結する価値 | 一つの気づきや考える問いを提示。結果を知るだけで課金を強制しない | 無料で既にわかるタイプ説明の単なる引き延ばしをしない |
| 個別性 | 回答内容を反映。ただし自己申告は性格の客観的測定ではない | 使用した暦計算・候補年・規則IDと、本人の選択による振り返りを区別 |
| キャラ | 生年月日による出生キャラはB04/B05・本番審査後。SNS共有は別機能 | キャラの珍しさより、読む体験が主役 |
| 想定する納品物 | Webで読める短い結果（予定）。保存や画像機能は後工程 | 長文鑑定の章立て、読み返せる形式などをMK03で正式確定 |
| 登録 | 無料体験のために連絡先を必須にしない案 | 商品購入時の必要情報は販売・個人情報設計で確認 |
| 価格 | 0円を想定 | 未決定。MK04で費用と支払意思を検討 |
| 公開可否 | M09.5プレビューが存在するが一般公開未承認 | N01／M06／N05等未承認。**販売不可・提供開始前** |

### コピー・訴求テスト用の3案（I）

1. 自己理解：「あなたの性格を決めるためじゃない。今の自分を読み直す、もちもち占術。」
2. 物語：「これまでの歩みを、別の角度から読んでみる。」
3. キャラ入口：「もちキャラから始まる、あなたのものがたり。」

上記は作品の企画コピー候補であり、テスト済みの効果はない。広告で現時点の未実装機能が使えるかのように告知しない。

## 6. なぜ選ばれるか：USP候補と信頼の根拠

- **差別化仮説（I）**：キャラで入り、暦の象徴をきっかけに過去・現在・未来を一本の読み物として扱う。自分の回答を振り返る余地を残す。
- **確認できる根拠（F）**：M08分類コード、M09表示コード、B03独自分類ルール、N02/N04の架空年表試作、原典調査・検証履歴。これらは実装経過の説明に限られる。
- **未実証（U）**：業界唯一、最も当たる、購入者満足度が高い、AI占いより正確、恋愛や人生が改善する。
- **訴求上の不採用**：不安を煽る「この年に不幸が来る」「知らないと運を逃す」、型による人格・優劣の決めつけ、有料を買えば運命が変わるとの表現。
