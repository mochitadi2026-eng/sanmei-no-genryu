## 2. 判定ルール

- **整備済**：設計書／コード／明示された運用実体を確認（品質や成果の成功とは別）。
- **一部**：仮説・草案・試作はあるが、販売運用に接続されていない。
- **不足**：この監査時点で販売・計測に必要な仕様・実績を確認できない。
- **未確認**：他のサービスや別システムに存在する可能性があるため、不存在を断言しない。
- **後工程**：初期MVPの必須条件でなく、実績が出てから判断する。

## 4. 5つの仮説ペルソナ（前回会話の整理）

これは人口統計上の実測セグメントではない。年齢はイメージ上の参考値。

| ID | 動機 | 主なペイン | 想定する体験 |
| --- | --- | --- | --- |
| P-A 自己理解 | 自分の特徴を知りたい | 強み・傾向の言語化が難しい | キャラ＋自分を振り返る問い |
| P-B 人生の転機 | これからの選択を考えたい | 進路・仕事・人生の迷い | 過去→現在→未来の読み物 |
| P-C 人間関係 | 相手との違いを理解したい | 恋愛・対人関係の距離感 | 価値観や関係性を見つめ直す |
| P-D エンタメ共有 | 気軽に楽しみたい | 長く難しい診断は面倒 | 短い結果・キャラ共有 |
| P-E 納得探究 | 根拠を確認したい | 汎用的・断定的な鑑定への疑問 | 出典・暦の計算と解釈の分離 |

**仮の戦略**：P-Dを認知の入口、P-Aを無料体験の中心、P-B／P-Cを深い体験の候補、P-Eは全体の信頼品質の要件。購買率が確認されるまで最優先顧客は確定しない。

## 5. 顧客体験と販売ファネル（案）

1. SNS／検索／note：認知を得る。
2. もちもち専用LP：提供すること・しないことを説明する。
3. 無料診断：独立した価値がある結果を返す。
4. 希望者だけが案内登録：同意を得て連絡先等を管理する。**匿名診断利用＝リードではない**。
5. 読み物・開発の検証説明：興味と信頼を育てる。
6. 詳細商品ページ：価格、サンプル、範囲、制約、決済・返金条件。
7. 購入／納品／サポート：購入後の体験を保証できる運用にする。
8. 再訪／任意共有：役立った人が戻り、紹介できるようにする。

初期の登録区分：Visitor（訪問）／User（匿名体験）／Lead（継続案内に同意）／Customer（購入）／Repeat Customer（追加購入）。MQL／SQLやスコアリングは必要になってから導入。

**既存の無料鑑定受付（上限100・受付停止）と、もちもち占術の将来の登録は別物として扱う。停止中の受付を無断再開しない。**

## 6. 商品階層仮説（価格・販売決定ではない）

| 階層 | 役割 | 追加価値の方向 |
| --- | --- | --- |
| 無料基本診断 | 体験・共感・共有 | 自分のもちキャラと現在の振り返り |
| 無料読み物・源流資料 | 理解・信頼 | 暦、五行、占術の前提と限界 |
| 低価格教材 | 初回購入 | 学び・ワーク・読み方の実践 |
| 個別物語鑑定 | 中核候補 | 暦の検証を通した時間軸の読み解き |
| 年次振り返り | 継続候補 | 過去の選択・現在の状況を振り返る |

**未承認の大運・年運から、実人物の転機年や事実を断定する有料鑑定を販売しない。** 過去のnote教材に関する参考価格は、もちもち占術の正式価格ではない。

## 7. 計測設計

最初に実装を検討するイベント：
`landing_view`、`diagnosis_start`、`diagnosis_complete`、`lead_opt_in`、`product_view`、`purchase_complete`。個人の生年月日・診断回答を分析イベントへ無断送信しない。

| 指標 | 定義／注意 |
| --- | --- |
| LP→診断開始率 | 診断開始ユーザー数 / LP訪問ユーザー数（同じ期間・重複排除ルールが必要） |
| 診断完了率 | 完了数 / 開始数 |
| 登録率 | 同意済み登録者数 / 対象ユーザー数 |
| 商品閲覧率 | 商品閲覧者数 / 診断完了者数 |
| 購入CVR | 購入者数 / 商品ページ訪問者数など、分母を固定 |
| CAC | 新規顧客獲得費用 / 新規購入者数 |
| ARPPU | 売上 / 購入者数 |
| LTV | 顧客1人が期間中にもたらす累積収益。売上／粗利ベースを明記 |
| 損益 | 売上 − 変動費 − 固定費（本人の運営工数も別途可視化） |

暫定NSM候補：**有効な無料診断完了人数／週**。満足や本人の納得は完了数だけでは証明されないため、任意の満足度・自由記述評価を別途行う。ベースライン・目標値は実測前に捏造しない。

## 8. 法務・安全・公開ゲート

- 占術の記号や計算の再現性と、人格・未来予測の科学的妥当性を混同しない。
- 顧客の不安を煽って購入を迫らない。健康・財産・結婚などに関する断定的な結果保証をしない。
- 個人情報：何を取得するか／保存期間／削除／閲覧権限／第三者提供／同意の撤回を明文化。
- 有料販売：特商法の表示、価格・納期・提供方法・解約／返品条件・注文確認・問い合わせを確認。
- 広告・紹介：景品表示法、レビュー利用時の許諾、ステマ規制、比較広告を確認。
- キャラの権利：素材・引用・商標等の商用利用条件を確認。
- 誤計算や障害に対する訂正・返金・顧客告知手順を設計。
- 本監査の記録は**公開・募集再開・課金開始・本番デプロイの承認ではない**。
