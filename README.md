# 算命の源流

**自然を読み、時を数え、人の命を考えた歴史。**

現代の算命学を入り口に、中国古代の占術・暦・五行・干支・命理を、出典をたどりながら読み直すプロジェクトです。史実、伝世文献の記述、現代の解釈、創作上の比喩を区別します。**章の順番は読者の理解の順番であり、文献の成立順や直系の伝承を示しません。**
