# 算命の源流 — 史料調査と読み物制作

既存の `AGENTS.md` と `RULES.md` を優先。調査で「正しさ」を装うより、実際に確認できた史料の境界を守る。

## 調査の手順

1. 対象の `articles/*.md`、`sources/registry.md`、`research/claims.md`、`research/questions.md` を読み、既存のS番号とC番号を再利用する。
2. 章が答える問いを一つに定める。「年代・人物・文献・計算法・日本側の成立」を混ぜた問いは、検証可能な小問に分ける。
3. 優先して同時代史料や原典本文を確認する。伝世本文の場合は刊本、原著帰属、後世の編纂、注釈を識別する。二次研究は本文確認と抄録確認を区別する。
4. 各主要主張について [出典記録テンプレート](references/source-record.md) の項目を埋め、判定を **史料に記載／研究で確認／現代実務で確認／解釈／伝承／未確認** から選ぶ。
5. 「その時代に書かれた」と「後代がその時代を語った」を比較し、矛盾・異説は消さずに残す。
6. 現代日本の算命学と照合するときは、**名称／意味／算出規則／時代／直接の伝承** を個別に検証する。現代民間サイトから歴史的な初出を導かない。
7. 読み物を `articles/*.md` に執筆・修正し、対応する `research/*.md` に原典・仮説・比較表・未解決課題を残す。
8. `sources/registry.md` にS番号、`research/claims.md` にC番号、必要なら `research/questions.md` に次の調査を追記する。
9. `python scripts/build_site.py` でHTMLを再生成し、`python scripts/validate_research.py` で記事・出典ID・タイトル・内部リンクの整合性を検査する。さらに[公開前チェックリスト](references/release-checklist.md)で内容面を検証する。
10. 修正した事実と未確認事項、リンクをチェックした範囲、公開反映の有無を簡潔に報告する。

## 重要な判断

- **一次資料にない情報を作らない。** 史料の時代・著者・章名・引用を思い出しだけで確定しない。
- 読めないURL、入手できない原本、論文の本文未閲覧は作業停止理由ではなく「未確認」として残し、根拠が不足する断定を削る。
- 出典数を増やすだけでは検証にならない。主張を支える具体的な章節・原文の範囲を示す。
- 正誤が確定していない場合は静かに書き換えて済ませず、研究ノートに保留点を残す。
- ユーザーが頼んでいない新章追加・デザイン刷新・自動公開設定には手を広げない。

## ファイルの役割

- `AGENTS.md`: Codexへの恒常的な指示
- `RULES.md`: 調査・記述の判定基準
- `EDITORIAL.md`: 本文の文体と編集方針
- `articles/`: 公開本文のMarkdown（マスター）
- `research/`: 逐条検証・差異・未確認事項
- `sources/registry.md`: 出典台帳
- `docs/`: GitHub Pages用の生成HTML（本文の手修正はしない）

成功条件は、**確認できたことが読者にも検証可能で、確認できなかったことが隠されていない**こと。
