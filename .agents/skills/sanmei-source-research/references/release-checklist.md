# 読み物公開前のチェック

## 出典
- [ ] 引用を実際に確認した。原典の内容と訳・解釈を混ぜていない。
- [ ] 著者帰属／成立年代／伝世版本／作中の時代を区別した。
- [ ] 抄録のみ閲覧した研究を、本文を読んだかのように紹介していない。
- [ ] 結論の各重要文にS番号を付け、台帳で該当箇所に到達できる。
- [ ] 刊本未校合・論文未読・伝承などの留保を本文と研究ノートに残した。

## 表現
- [ ] 記事の順番を流派の成立順に見せていない。
- [ ] 「初出」「完成」「由来」「直接継承」を裏づけなく断定していない。
- [ ] 日本側の星名・点数・キャラと中国古典の十二段階を混同していない。
- [ ] 一記事に一つの問い、読後に確認できた発見が一つ残る。
- [ ] 古典の人名・死・絶・病・吉凶の語を現代個人の断定に転用していない。

## ファイル・公開
- [ ] `articles/*.md` をマスターとして更新。
- [ ] `sources/registry.md` と `research/claims.md` を同期。
- [ ] `research/questions.md` に未解決課題を追加。
- [ ] `scripts/build_site.py` で配信HTMLを生成。
- [ ] 全ページの内部リンク、S番号、目次のタイトル、前後記事を点検。
- [ ] GitHubコミットとGitHub Pages反映を別々に報告。
