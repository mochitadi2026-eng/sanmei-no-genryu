# 史料・主張の記録テンプレート

新しい史料を追加するときは、分かる欄を埋める。該当情報がない欄は捏造せず「未確認」。公開の出典台帳へは短く要約して転記する。

## Source record
- S番号：
- 著者・編者（伝承上の帰属と区別）：
- 書名・論文名：
- 巻・篇・節・該当箇所（頁／行／刻辞番号等）：
- 文献成立年代（推定なら根拠）：
- 今回見た媒体（翻刻／影印／原物／論文本文／抄録等）：
- 確認可能なURL・書誌・所蔵館：
- 実際に確認した内容（必要な短い原文／要約）：
- 別の本文・異本・異説：
- 確認日：
- 限界と未確認：

## Claim record
- C番号：
- 公開予定の日本語の主張：
- 分類：史料に記載／研究本文で確認／抄録のみ／現代実務で確認／解釈／伝承／未確認
- 根拠のS番号と具体箇所：
- 他の読み方・反証可能性：
- 表現の上限（言えることと言えないこと）：
- 関連する本文ファイル：

## 比較調査の注意

対応表を作るとき、**現代の計算上の対応**と**歴史の継承**は別の列にする。『五行精紀』等の見出しが同じでも、後世と同じ意味であると前提しない。
